## 📌 Project Objective
A highly interactive, dark-themed Power BI dashboard designed to simulate a real-time satellite tracking ground station. This project goes beyond standard business intelligence by integrating orbital physics and aerospace telemetry into dynamic data visualizations.

## 🛠️ Key Features & Technical Implementations

* **Live Trajectory Tracking:** Visualizes Azimuth and Elevation data to track satellite paths across a global radar scope.
* **Physics Computation Engine (DAX):** Calculates real-time orbital velocity using the standard gravitational parameter.
  * Formula implemented in DAX: $V = \sqrt{\frac{GM}{r}}$
* **Horizon Visibility Logic:** Uses conditional formatting and calculated columns to instantly alert operators when a satellite breaks the horizon (Elevation > 0°).
* **Advanced UI/UX:** Features a sleek "Mission Control" aesthetic using Power BI's Bookmarks, Selection Pane, and Page Navigators to create immersive, app-like pop-up menus and fluid navigation.

## 🛰️ Satellites Tracked
1. **CARTOSAT-3** (Earth Observation)
2. **GSAT-30** (Telecommunication)
3. **IRNSS-1I** (NavIC Regional Navigation)
4. **RISAT-2B** (SAR Imaging)
